# 渓水寮サイト・Wiki台帳

## プロジェクト構造

```text
pages/                         URLルート入口（ファイル名とURLを維持）
├── index.js                   トップページ /
├── wiki.js                    Wikiホーム /wiki/
├── [...slug].js               Markdown記事のURL
├── about.js・life.js・...      既存ページURL
└── messages/                  寮生の声の既存URL

src/
├── home/                      トップページ表示
├── site/
│   ├── components/            ナビ・ヘッダー・フッターなど共通部品
│   └── pages/                 既存ページ本文の実装
└── wiki/
    ├── components/            Markdown記事の表示部品
    ├── WikiHomePage.js        Wikiホームの表示
    └── loadWikiData.js        分類・記事の読み込み

content/
├── wiki/                      分類フォルダとMarkdown記事
└── legacy-voices.json         寮生の声の既存データ

public/                        画像・配布文書など
styles/                        全体・ページ別スタイル
```

既存ページのURL入口は `pages/` に残し、本文実装は `src/site/pages/` に置く。Wikiに載せる既存ページは本文を移さず、分類フォルダの `pages.json` に名前とURLを記録する。

## 運用方針

Wikiトップ `/wiki/` と記事ページは、`content/wiki/` の分類フォルダを読み込んで生成する。分類・記事の追加や移動は、同じフォルダ構造の中で行う。

- トップページ `/` と現行ページの本文・URLを維持する。
- 現行ページはMarkdown化せず、各ページの既存URLへリンクする。
- 新しいMarkdown記事は独立したURLで公開する。`/about/` や `/compare/` の配下には置かない。
- 既存の `/compare/` は現行ページとして残し、「住まいと生活費の比較」と別に扱う。
- databaseから同じ原文を重複保存しない。公開用記事は分類フォルダのMarkdownを編集し、必要な参考資料だけ `docs/wiki/参考資料/` に置く。
- 会議録、個人情報を含む記録、未確定の募集案はWiki記事に登録しない。

## フォルダの構造

```text
content/wiki/
├── 理念・背景/
│   ├── _category.json       分類名と表示順
│   ├── pages.json           この分類に属する既存ページ
│   ├── 渓水寮の理念.md      Wiki記事
│   ├── 東北大学基督教青年会寄宿舎の精神.md
│   └── なぜ渓水寮か.md      Wiki記事
├── 暮らし/
│   ├── _category.json
│   └── pages.json
├── 費用・入寮/
│   ├── _category.json
│   ├── pages.json
│   └── 住まいと生活費の比較.md
└── つぶやき/
    ├── _category.json
    ├── pages.json
    └── 新寮の想い.md
```

各分類フォルダがWikiトップの分類ひとつに対応する。`_category.json` が分類名と表示順、`pages.json` はMarkdownではない既存ページへのリンク、フォルダ内のMarkdownファイルがWiki記事となる。記事のメタデータはMarkdown先頭のJSON形式front matterに置く。

分類フォルダは `src/wiki/WikiHomePage.js` と `src/wiki/loadWikiData.js` が自動で読み込む。記事ページの静的生成処理は `pages/[...slug].js` に置く。新分類を追加するときは、分類名のフォルダと `_category.json` を作れば、Wikiトップに分類が追加される。Markdown記事だけの分類には `pages.json` は不要。新しいMarkdown記事はそのフォルダに置き、front matterを付けると目次・記事URL・静的出力に反映される。既存ページを分類に加える場合だけ `pages.json` に登録する。

## 記事の追加方法

Markdown記事のfront matterはJSONで記述する。例：

```markdown
---
{
  "id": "example-article",
  "title": "記事タイトル",
  "route": "/example-article/",
  "description": "Wikiトップに表示する短い紹介文",
  "related": [
    { "href": "/life/", "title": "寮生活" }
  ]
}
---

記事本文
```

記事を追加する手順は次のとおり。

1. 掲載する分類フォルダにMarkdownファイルを作り、front matterに重複しない `id` と `route`、タイトル、説明、関連記事を設定する。
2. 記事のURLを `public/sitemap.xml` に追加する。
3. ブラウザでWikiトップ、記事本文、関連記事、直接URLを確認する。

記事メタデータには必要に応じて `author`、`date`、`stripFirstHeading`、`linkReplacements` を指定できる。関連記事の逆リンクは自動生成しないため、必要なら相手の記事にも追加する。

既存ページをWikiに加えるときは、該当分類の `pages.json` に `id`、`title`、`route` を登録する。分類を追加するときは `_category.json` の `title` と、重複しない `order` を指定する。同じURLを誤って両方に登録してもMarkdown記事を優先し、Wikiトップには重複して表示しない。

## 確認事項

- 「渓水寮の理念」の理念が採択済みか、現行運営と一致しているか確認する。
- 「なぜ渓水寮か」は著者、比較対象の表現、掲載承認を確認する。
- 生活費比較の学寮は東北大学の以文寮を例にし、寮費全額月17,000円を比較上の前提としている。内訳や生活条件の確認を続ける。
- 「新寮の想い」はつぶやき分類の記事として掲載する。
- 各記事に追加・変更を加えた際は、出典、料金、日付、掲載承認を再確認する。
